# Maycha web app

Next.js frontend for the Maycha ordering application. Run frontend commands from this directory.

```powershell
npm install
npm run dev
```

The development server is available at `http://localhost:3000`. Set `NEXT_PUBLIC_API_URL` in `.env.local` to override the API URL (default: `http://localhost:3001`).

Use `npm run lint` and `npm run build` to validate the frontend. For the complete local deployment, see the repository [README](../../README.md).
